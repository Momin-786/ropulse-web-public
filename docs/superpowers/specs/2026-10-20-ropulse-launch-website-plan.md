# Website implementation plan

The owner approved the design and instructed implementation. The referenced
writing-plans skill is not installed; this plan records the implementation
sequence directly. Work remains in the supplied local workspace.

1. Scaffold Next.js/TypeScript, security headers and environment configuration.
2. Copy the approved web logo/icon assets. Build the responsive brand shell,
   homepage and focused product/solution pages using the PDF's design tokens.
3. Build the explicit article manifest, safe Markdown renderer, stable links,
   role/task navigation, table of contents and local full-text search.
4. Build contact validation/delivery with honest unavailable/error states,
   legal publication boundaries, release downloads and identity entry points.
5. Add metadata, robots/sitemap, publication controls and readiness checks.
6. Run content/security tests, typecheck and production build. Exercise the
   rendered site at desktop/mobile sizes and correct observed issues.
7. Deliver setup, deployment/rollback, publication and QA documentation with
   explicit external-service launch dependencies.
