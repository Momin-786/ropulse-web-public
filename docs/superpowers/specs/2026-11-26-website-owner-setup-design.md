# Website owner setup and Register pairing

Owners use the existing subscriber sign-in at `/account` to open setup or Register management for a workspace. Billing remains separate from both. Setup shows the server readiness checklist and saves the same owner confirmations as the Flutter owner setup screen. Register management shows the workspace-wide terminal usage, licensed branches, and devices. It creates one short-lived code for a selected branch using the existing owner-only licensing endpoint and shows the code and expiry in memory. Owners can refresh to confirm the device paired. Authorization, slot reservation, expiry and code redemption remain owned by the API. Verify the flow with a test workspace and confirm billing and sign-out still work. No database change is required.
